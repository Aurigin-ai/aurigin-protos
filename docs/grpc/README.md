# gRPC HTML docs

Auto-generated by `pseudomuto/protoc-gen-doc` from every `.proto` under
`../proto/`. One single-page `index.html` covering all services,
messages, and enums.

Regenerate after any proto change:

```bash
./scripts/generate-docs.sh
```

The script runs the plugin via Docker (`pseudomuto/protoc-gen-doc:1.5.1`)
— no local protoc install needed.

Committed to the repo so downstream consumers (the
`platform-backend-services` local api-docs portal, future SDK docs
sites, partner-facing reference pages) can serve a known-good render
without having to run protoc themselves.

CI (follow-up) will fail PRs that touch `.proto` without refreshing
this directory — see `.github/workflows/docs.yml` once it lands.

## Not shipped in SDK packages

The published Python (`aurigin-protos` on PyPI/CodeArtifact) and
TypeScript (`@aurigin/protos` on npm/CodeArtifact) packages are built
from `gen/py/` and `gen/ts/` — this directory sits outside both
`packages` (Python `pyproject.toml`) and `files` (TypeScript
`package.json`), so the HTML never ends up in a user's `pip install`
or `npm install` tree.
